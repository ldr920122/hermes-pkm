# 从日记分析碳水循环状态

## 触发场景

用户问"今天该低碳还是高碳"、"今天能吃什么"、"帮我看看最近饮食"时触发。

## 日记格式识别

该用户的日记有两种内容格式混合：

**格式A - BuJo 基础模板**（`🎯 今日三件事`、`📋 任务`、`📝 笔记`、`🔄 明日预览`）

**格式B - Gemini 生成的饮食训练日志**（以 `# 📅 YYYY-MM-DD` 开头），固定结构：
- `## 🍽️ 今日饮食记录` → 分早餐/午餐/加餐/晚餐/夜宵，每项带战术复盘
- `## 🏋️ 今日训练记录` → 训练部位、动作、重量、组数，可能有有氧记录
- `## 📊 状态评估` → 当日复盘 + "赛博搭子锐评" + "明日行动指南"
- 标签：`#饮食日记 #练腿日 #高碳日 #Obsidian` 等

识别碳水策略的关键词：
- `极致低碳` `严格低碳` `脱水刮油` `零碳水` → 低碳日
- `高碳` `充能` `大餐` `放纵` `欺骗餐` → 高碳/放纵日
- `暴食` `失控` `疲惫型暴食` → 失控日（需后续防守）
- `防守` `刮油` `逆袭` → 补救/防守日
- `恢复` `干净充能` `适度碳水` → 恢复日

## 分析步骤

1. **确定时间窗口**：默认近 7 天，可调整
2. **批量读取日记**：`子弹笔记/日记/2026-05-XX_YYY.md` 格式
3. **提取每日本质**：不看细节，看策略标签和训练部位
4. **画时间线表**：日期 | 训练 | 碳水策略 | 关键事件
5. **检查"明日行动指南"**：最近一天的日记底部通常有次日建议，优先采纳
6. **判断今日类型**：
   - 连续低碳 + 高强度训练 → 恢复充能日（100-150g 干净碳水）
   - 前一天暴食 → 极致低碳防守日（<50g 碳水）
   - 练腿日前夜 → 可适当加碳水（为训练储备糖原）
   - 休息日 → 低碳维持（<80g 碳水）
7. **结合训练计划调整**：如果用户说今天要去练，碳水预算上调 30-50g
8. **给出具体食物建议**：玉米、紫薯、燕麦、糙米 → 干净碳水；白米饭、面条 → 精细碳水（仅练后窗口）
9. **算账**：把已摄入和预算对比，给用户剩余额度

## 注意事项

- 用户做碳水循环（carb cycling），不是纯低碳或纯高碳
- 练腿日碳水需求最高，休息日最低
- 用户日记里"明日行动指南"是用户自己的规划，应该优先采纳而非覆盖
- 沙县小吃是用户的固定练后餐：去皮鸡腿 + 水煮菜 ± 土豆丝（练日加，休息日砍）
- 椰子水 = 天然碳水 ~12-15g/杯，算在预算内，不算违规
- 美式/蛋白粉/魔芋豆腐 = 零/极低碳水，不算预算
- 玉米 ≈ 20-25g/根，紫薯 ≈ 30-40g/个，糙米饭 ≈ 45g/碗

## 输出格式

给用户的回复应该：
1. 过去一周碳水策略汇总表（一目了然）
2. 今日判断 + 理由（引用日记原文证据）
3. 具体碳水预算（数字）
4. 对用户提出的具体食物给出 YES/NO + 理由
5. 如果训练计划变了，即时调整预算
