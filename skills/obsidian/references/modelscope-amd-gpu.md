## 上手教程

推荐：研习社文章「AMD GPU × Qwen3.6-35B 模型初体验：零成本玩转大模型部署」（2026-05-21，作者 catbohe）

步骤：领 GPU → 启动 Notebook → 下载模型（modelscope SDK）→ 切换 GPU 实例 → 加载模型 → 对话测试

关键技巧：
- 首次下载模型用 CPU 实例（更快），下载后切 GPU 实例
- 模型缓存后再次加载秒开
- 使用 `attn_implementation="flash_attention_2"` 速度提升 50%
