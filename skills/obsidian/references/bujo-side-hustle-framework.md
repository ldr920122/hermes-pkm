# Bullet Journal Side-Hustle Framework（副业探索 · 多线并行）

When user discusses career exploration / side hustle direction, use this framework
to structure their monthly action plan with parallel tracks instead of sequential choices.

## The Pattern

Add a `🚀 副业探索` section to the monthly action plan. Structure as numbered parallel lines:

```markdown
### 🚀 副业探索 · N线并行

> 目标：主业外建立第二曲线

**线1️⃣ <方向名>（输出类型 · 独特优势）**
- [ ] 最近的启动动作
- [ ] 下一步

**线2️⃣ <方向名>（输出类型 · 独特优势）**
- [ ] ...
```

## Design Principles

1. **Inventory first, then rank.** Before suggesting directions, list the user's
   ALL assets: AI skills, hardware, professional domain, content creation, code
   — everything. This prevents overlooking non-obvious combinations.

2. **Rank by startup cost × overlap with current life.** The best direction is
   one that requires zero new equipment/learning and overlaps with what they
   already do daily. Present a comparison table: startup cost vs current overlap.

3. **Parallel, not sequential.** P-people get overwhelmed by "pick one."
   Multiple lines that share the same skill base don't compete — they compound.
   Progress on one feeds the others.

4. **Video/creative goes last.** If user mentions video/UP主/creative ambitions,
   acknowledge them but place them in a `待评估` section. Creative content needs
   sustained output before monetization; prioritize the direction with fastest
   feedback loop first.

5. **"Tonight" test.** Each line must have at least one action that can be
   started tonight with zero prep. If not, the direction is too abstract.

## Example: AI + Hardware + Code (this user)

Three lines share the same AI workflow skills:
- Line 1: AI workflow consulting (write an article, find a test client)
- Line 2: 3D print + UV customize (design one saleable item)
- Line 3: AI code tools (sign-in machine is MVP)

## When to Use

Trigger: user mentions 副业, career change, 职业规划, side project monetization,
"想赚点钱", "时间不够用", creative ambitions, or feeling stuck in current job.

## Pitfalls

- Don't suggest directions that need new equipment unless they explicitly own it
- Don't let "待评估" directions crowd the active lines — max 3 active
- After creating the framework, steer to ONE concrete action user can do this week
