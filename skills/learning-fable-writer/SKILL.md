# 寓言故事创作工作流

## 概述

为 Obsidian wiki 的「学习方法的寓言小故事」系列创作教育寓言。故事通过叙事间接讲解学术概念，读者在快结尾时才意识到讲的是什么。

## 目录结构（关键发现）

每个概念是一个**子目录**，内含 .md 和 .html 文件：

```
学习方法的寓言小故事/
├── 统计学/
│   ├── 多重比较问题/
│   │   ├── 多重比较问题.md
│   │   └── 多重比较问题.html
│   ├── 贝叶斯推断/
│   │   ├── 贝叶斯推断.md
│   │   └── 贝叶斯推断.html
│   └── ...
```

⚠️ **陷阱**：目录名就是概念名，不是扁平文件。创建时必须 `mkdir -p` 子目录。

## 工作流程

### 1. 检查已有故事（必做）
```bash
ls /Users/wbaoc/Documents/Obsidian/wbaoc-wiki/wiki/学习方法的寓言小故事/{学科}/
```
读取已有概念列表，避免重复选题。

### 2. 选题原则
- 选择研究生水平的概念（不要太基础）
- 概念必须能通过叙事间接表达（有隐喻空间）
- 检查已有故事的风格，确保下一篇风格不同

### 3. 风格多样性（核心要求）
每篇故事的叙事风格、角色、场景都要不同。可选风格池：
- 寓言/童话
- 神话/传说
- 武侠/江湖
- 都市/现代
- 科幻/太空
- 民间故事
- 历史/宫廷
- 悬疑/推理

已有风格记录（避免重复）：武侠（多重比较问题、辛普森悖论）

### 4. 文件格式

YAML frontmatter：
```yaml
---
title: "寓言：{故事标题}"
category: 杂项
tags: [寓言故事, 学习方法, 统计学, {概念名}]
created: {YYYY-MM-DD}
---
```

内容结构：
```markdown
# {故事标题}

## 📖 寓言
（故事内容 — 间接讲解概念，快结尾时才揭示）

---

## 🔍 概念解析
（概念的正式解释，包含：
 - 一句话定义
 - 数学直觉/公式
 - 常见方法/对比表格
 - 现实典型场景
 - 核心教训）
```

### 5. 故事写作要点
- **间接性**：故事本身不提概念名称，直到解析部分才揭示
- **隐喻映射**：故事中的元素要能一一对应概念的组成部分
- **节奏**：铺垫→困境→顿悟→（读者意识到概念）→解析
- **结尾金句**：用一句话总结核心教训，加粗

### 6. 保存路径
```
/Users/wbaoc/Documents/Obsidian/wbaoc-wiki/wiki/学习方法的寓言小故事/{学科}/{概念名}/{概念名}.md
```
